# mj-market-analysis

Claude Code skill：亚马逊全类目深度市场调研报告生成流程（大盘、竞品、VOS 流量、VOC 痛点、广告入场判断），输出结构化的 5 章飞书报告。

## 安装

把整个文件夹放到 `~/.claude/skills/mj-market-analysis/`。

## 依赖

- 数据：西柚（xydc-mcp）、卖家精灵（sellersprite-mcp）、Sorftime 等 MCP，需自备账号
- 输出：飞书 lark-cli
- 部分步骤引用作者其他未公开的 skill（如 mj-ad-entry-screen），缺少时可跳过对应模块

详细流程见 [SKILL.md](SKILL.md)。
